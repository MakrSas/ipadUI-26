# iPadUI 26

Твик для iOS 26 (rootless), который включает на iPhone интерфейс iPadOS: плавающий док с
недавними приложениями и Библиотекой приложений, сетку переключателя приложений
(«таск-менеджер» iPad), Split View и Slide Over, Stage Manager, домашний экран и статус-бар
iPad, поворот домашнего экрана и iPad-раскладку внутри приложений.

## Возможности

| Раздел | Что делает |
| --- | --- |
| Домашний экран iPad | SpringBoard работает в режиме интерфейса iPad: плотная сетка иконок, виджеты, iPad-раскладки Пункта управления, Центра уведомлений и экрана блокировки |
| Статус-бар iPad | Время и дата слева, Wi-Fi и процент заряда справа — в SpringBoard и в приложениях |
| Поворот домашнего экрана | Домашний экран и экран блокировки поворачиваются в альбомную ориентацию |
| Плавающий док | Док iPad, вызывается свайпом поверх приложений; отдельно включаются недавние приложения и Библиотека приложений |
| Переключатель приложений | Сетка iPad вместо колоды карточек iPhone |
| Split View и Slide Over | Два приложения рядом и плавающее окно, перетаскиванием из дока |
| Stage Manager | Окна с изменяемым размером (экспериментально, по умолчанию выключено) |
| Раскладка iPad в приложениях | Боковые панели, split view, поповеры, клавиатура iPad; есть список исключений (по умолчанию выключено) |
| Класс устройства | Подмена ответов MobileGestalt (`DeviceClass`, `DeviceClassNumber`, флаги многозадачности) только внутри SpringBoard |

## Настройки с живыми превью

Настройки открываются двумя способами: «Настройки» → **iPadUI 26** (через PreferenceLoader)
или отдельным приложением **iPadUI 26** на домашнем экране. Приложение показывает те же
страницы и работает, даже если PreferenceLoader на вашей версии iOS не загружается. На каждой странице есть превью,
которое рисует сама iOS, а не картинка: оно собрано из настоящих UIKit-вью — Liquid Glass
(`UIGlassEffect` на iOS 26, системный материал на более старых версиях), настоящие иконки
установленных приложений и их локализованные названия, SF Symbols и текущее время в статус-баре.
Превью следуют светлой/тёмной теме, при переключении любой опции плавно перестраиваются с
пружинной анимацией, а превью переключателя, Split View, Stage Manager и поворота
проигрывают короткую демонстрацию (отключается при «Уменьшении движения»).

Интерфейс настроек переведён на русский и английский.

## Сборка

Нужен [Theos](https://theos.dev).

```sh
make package FINALPACKAGE=1
```

Готовый `.deb` появится в `packages/`. Для arm64e на iOS 15+ собирайте тулчейном Xcode
(macOS) — так же делает GitHub Actions в `.github/workflows/build.yml`, где пакет
публикуется как артефакт сборки. Для roothide-джейлбрейков пакет можно конвертировать
через Roothide Patcher.

## Как это устроено

- `Sources/Tweak.m` — точка входа: решает, что включать в SpringBoard, а что в приложениях
  (демоны и расширения не трогаются).
- `Sources/PUSpringBoard.m` — хуки SpringBoard: док, переключатель, многозадачность,
  Stage Manager, поворот.
- `Sources/PUMobileGestalt.m` — подмена MobileGestalt через `MGCopyAnswer_internal`.
- `Sources/PUUIKit.m` — статус-бар iPad и iPad-идиома в приложениях.
- `Sources/PUHook.m` — все хуки ищутся в рантайме и проверяются по типу возвращаемого
  значения. Если класса или метода нет в установленной версии iOS, хук пропускается и пишется
  в Консоль с префиксом `[iPadUI26]` — SpringBoard от этого не падает.
- `iPadUI26Prefs/` — бандл настроек и живые превью (`PUPreviewKit.m`, `PUPreviews.m`).
- `iPadUI26App/` — отдельное приложение, которое загружает бандл настроек.

## Важно

- Это приватные API SpringBoard, Apple меняет их от версии к версии. Если какая-то функция
  не включилась, откройте журнал: «Настройки» или приложение iPadUI 26 → **Журнал**
  (файл `/var/jb/var/mobile/Library/Logs/iPadUI26.log`). Строки `skip ...` показывают,
  какого метода не нашлось. Те же строки с префиксом `[iPadUI26]` есть в системном журнале.
- Если после респринга что-то пошло не так, загрузитесь в безопасном режиме вашего
  джейлбрейка и выключите проблемную опцию.
